# Вклад в проект

Проект выпускается под GPL-3.0-or-later ([LICENSE](LICENSE), [ADR 0006](docs/adr/0006-project-license.md)).

1. Прочитай [AGENTS.md](AGENTS.md): правила безопасности и доказательств действуют и для людей.
2. Подписывай каждый коммит по DCO: `git commit -s` добавляет строку `Signed-off-by: Имя <email>`.
3. Подпись значит: ты написал код сам или он взят из источника с совместимой лицензией, и ты вправе передать его проекту под GPL-3.0-or-later.
4. Не добавляй код производителя Модуля, его декомпиляцию и цитаты.
5. Не добавляй зависимости с лицензией, несовместимой с GPL-3.0.
6. PR открывай в `main`. Merge выполняет владелец.

Полный текст DCO: <https://developercertificate.org>.
