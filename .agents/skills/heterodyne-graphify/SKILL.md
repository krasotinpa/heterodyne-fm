# Поиск по коду Heterodyne FM

Работай из текущего worktree. Граф хранится только в игнорируемом `graphify-out/`.

Если задача допускает изменение файлов, выполни `graphify update .`, затем `graphify query "<вопрос>"`.
Для вызовов используй `--context call`; уточняй запрос при неоднозначных именах и усечённой выдаче.
Exit 0 не доказывает полноту: прочитай предупреждения о частичном разборе.
Проверь найденные связи чтением исходников; точные строки и символы ищи через `rg`.
Отсутствие узла или связи также проверь по исходникам.

Для задачи только чтения не обновляй граф и не создавай служебные файлы.
Если граф уже есть, можно выполнить `graphify query`; явно укажи, что свежесть графа не проверена обновлением.
Если графа нет или инструмент недоступен, используй исходники и `rg`, отметив отсутствие графа.
Не устанавливай и не обновляй пакеты как побочное действие поиска.

Полная семантическая сборка, watch, hooks и экспорт во внешние системы не входят в этот workflow.
Для них нужна отдельная задача с явными границами записи и внешних действий.
Известные ограничения Kotlin-парсера и правила проекта: [skills.md](../../../docs/agents/skills.md#проверка-graphify).
