# Heterodyne FM

Собственное Android-приложение для USB-радиомодуля на штатном головном устройстве Toyota Highlander.

## Language

### Оборудование

**Приёмник**:
Любое USB-устройство, с которым работает приложение: Модуль или RTL-SDR V4. В работе один Приёмник. Пользователь выбирает его в Режиме стоянки.
В тексте интерфейса пользователь видит слово «приёмник». Конкретное устройство называется только в «Диагностике».
_Avoid_: донгл, dongle, радио

**Модуль**:
Вид Приёмника: USB-устройство Super Radio. Аппаратно принимает AM и FM, приложение использует только FM. Имеет только разъём USB Type-A и разъём антенны.
_Avoid_: донгл, dongle, тюнер, радио

**RTL-SDR V4**:
Вид Приёмника: USB-устройство RTL-SDR Blog V4. Отдаёт сырой IQ-поток, звук получает само приложение.
_Avoid_: SDR, свисток, донгл

**Возможность**:
Свойство Приёмника, которое он объявляет: Поиск, отмена Поиска, RDS, уровень сигнала, стерео. Набор не меняется, пока Приёмник выбран. Элемент интерфейса виден, только если Возможность объявлена. Флаг включает тикет, который прошёл приёмку на ГУ.
_Avoid_: capability, фича, опция

**Тюнер**:
Микросхема приёма внутри Приёмника. У Модуля её тип пока не установлен.
_Avoid_: модуль, чип радио

**Приложение производителя**:
Чужое Android-приложение для Модуля, полученное от поставщика. Не часть нашего продукта.
_Avoid_: официальное приложение, штатное приложение, vendor app

**Кадр**:
Единица обмена данными между приложением и Модулем.
_Avoid_: пакет, сообщение, frame

**ГУ**:
Штатное Android-головное устройство автомобиля, на котором работает приложение.
_Avoid_: магнитола, head unit, HU

### Данные станций

**Регион**:
Географическая область со своим Справочником и своими Подборками, например Москва или Ярославль. Выбирается вручную.
_Avoid_: город, зона, location

**Справочник**:
Список радиостанций одного Региона. Приложение содержит снимок всех Регионов и работает с ним без сети. Пользователь обновляет Справочник вручную в Режиме стоянки, онлайн или из ZIP-файла. Пользователь Справочник не правит. Обновление не меняет Подборки.
_Avoid_: каталог, база станций, плейлист

**Ревизия**:
Дата версии набора Справочников. Приложение принимает набор только с Ревизией новее текущей. Пользователь может вернуть встроенный набор.
_Avoid_: версия, релиз, обновление

**Устаревший Регион**:
Регион, который пропал из нового набора Справочников, но у пользователя в нём есть Подборки. Остаётся в списке с пометкой, пока пользователь не удалит его.
_Avoid_: удалённый Регион, архивный Регион

**Подборка**:
Именованный упорядоченный список станций, который собрал пользователь внутри одного Региона. У Региона может быть несколько Подборок. Порядок задаёт пользователь.
_Avoid_: пресеты, избранное, список

**Станция**:
Радиостанция с именем и частотой FM. Встречается в Справочнике и в Подборке. В Подборке хранится независимая копия.
_Avoid_: канал, пресет, радио

**Частота вне Подборки**:
Текущая FM-частота, для которой нет имени в Активной Подборке и Справочнике выбранного Региона.
_Avoid_: неизвестная Станция, безымянный канал

**Активная Подборка**:
Подборка, с которой сейчас работают вкладка Подборки и кнопки руля. Для каждого Региона активна одна Подборка.
_Avoid_: текущий список, выбранный пресет

### Приложение

**Heterodyne FM**:
Наше приложение для Модуля на ГУ. Короткое имя — H-FM.
_Avoid_: Super Radio, радио, плеер

**Переход**:
Установка Модуля на Станцию из Справочника или Подборки.
_Avoid_: tune, настройка, выбор

**Шаг**:
Изменение частоты на одно деление командой TUNEUP или TUNEDOWN.
_Avoid_: step, перестройка

**Поиск**:
Переход к ближайшей Станции с сигналом командой SEEKUP или SEEKDOWN.
_Avoid_: seek, сканирование, автопоиск

**Сигнал Перехода**:
Тон, звук клавиши или тишина, по которым водитель слышит смену Станции. Способ выбирают в «Настройках».
_Avoid_: бип, звук переключения

**Лупа**:
Увеличенная полоса Станций вокруг точки касания шкалы диапазона. Видна, только пока палец на шкале.
_Avoid_: fisheye, зум, увеличитель

**Тема**:
Светлое или тёмное оформление приложения. Пользователь выбирает Авто (по данным ГУ), Светлую или Тёмную.
_Avoid_: режим, скин

**Палитра**:
Готовый набор цветов приложения со светлой и тёмной версией. Пользователь выбирает одну из нескольких.
_Avoid_: цветовая схема, акцент

**Режим движения**:
Экран для водителя на ходу: Активная Подборка, Справочник, Шаг, Поиск.
_Avoid_: главный экран, driving mode

**Режим стоянки**:
Экран для стоящего автомобиля: Регион, Подборки, настройки, диагностика.
_Avoid_: настройки, parked mode

**Журнал**:
Кольцевой файл на 10 МБ с кадрами и событиями приложения. Всегда включён. Серийник Модуля хранится в нём только хэшем.
_Avoid_: лог, трассировка

**Строка состояния**:
Строка под названием Станции в Режиме движения. Показывает Регион либо Причину выключения.
_Avoid_: статус-бар, баннер

**Причина выключения**:
Одна причина с наибольшим приоритетом, по которой кнопки Режима движения выключены. Показывается в Строке состояния без нажатий.
_Avoid_: баннер, подсказка, статус

**Режим разработчика**:
Скрытое расширение Режима стоянки: живой поток кадров и кнопки команд из whitelist. Включается жестом, выключается вручную.
_Avoid_: debug, инженерное меню
