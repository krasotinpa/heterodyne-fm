# Super Radio Android

Собственное Android-приложение для USB-радиомодуля на штатном головном устройстве Toyota Highlander.

## Language

### Оборудование

**Модуль**:
USB-устройство Super Radio с приёмом AM/FM. Имеет только разъём USB Type-A и разъём антенны.
_Avoid_: приёмник, донгл, dongle, тюнер, радио

**Тюнер**:
Микросхема приёма внутри Модуля. Её тип пока не установлен.
_Avoid_: модуль, чип радио

**Приложение производителя**:
Чужое Android-приложение для Модуля, полученное от поставщика. Не часть нашего продукта.
_Avoid_: официальное приложение, штатное приложение, vendor app

**Кадр**:
Единица обмена данными между приложением и Модулем.
_Avoid_: пакет, сообщение, frame

**ГУ**:
Штатное Android-головное устройство автомобиля, на котором работает приложение.
_Avoid_: магнитола, head unit, HU

### Данные станций

**Регион**:
Географическая область со своим Справочником и своими Наборами, например Москва или Ярославль. Выбирается вручную.
_Avoid_: город, зона, location

**Справочник**:
Встроенный в приложение список радиостанций одного Региона. Пользователь его не правит.
_Avoid_: каталог, база станций, плейлист

**Набор**:
Именованный упорядоченный список станций, который собрал пользователь внутри одного Региона. У Региона может быть несколько Наборов. Порядок задаёт пользователь.
_Avoid_: пресеты, избранное, список

**Станция**:
Радиостанция с именем, диапазоном и частотой. Встречается в Справочнике и в Наборе. В Наборе хранится независимая копия.
_Avoid_: канал, пресет, радио

**Активный Набор**:
Набор, с которым сейчас работают вкладка Набора и кнопки руля. Для каждого Региона активен один Набор.
_Avoid_: текущий список, выбранный пресет
