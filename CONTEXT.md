# Super Radio Android

Собственное Android-приложение для USB-радиомодуля на штатном головном устройстве Toyota Highlander.

## Language

### Оборудование

**Модуль**:
USB-устройство Super Radio с приёмом AM/FM. Имеет только разъём USB Type-A и разъём антенны.
_Avoid_: приёмник, донгл, dongle, тюнер, радио

**Тюнер**:
Микросхема приёма внутри Модуля. Её тип пока не установлен.
_Avoid_: модуль, чип радио

**Приложение производителя**:
APK `com.hyinfo.dab`, присланный поставщиком Модуля. Источник сведений о протоколе, а не часть нашего продукта.
_Avoid_: официальное приложение, штатное приложение, vendor app

**Кадр**:
Единица обмена с Модулем по CDC, начинающаяся с `FA 55`.
_Avoid_: пакет, сообщение, frame

**ГУ**:
Штатное Android-головное устройство автомобиля, на котором работает приложение.
_Avoid_: магнитола, head unit, HU
