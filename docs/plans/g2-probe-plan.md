# G2, часть 2: диагностическое приложение на ГУ

Исполнитель — владелец у автомобиля. Уровень воздействия: установка APK и подключение Модуля. Радиокоманд нет.
Цель — узнать процессор, ABI, память, видит ли ГУ Модуль по USB и появляется ли USB-аудиовход.

## Приложение

`research-tools/g2-probe/` — Super Radio Probe 0.1, один экран с текстом.

1. Только читает: `Build`, `/proc/cpuinfo`, объём ОЗУ, список USB-устройств и аудиоустройств.
2. Для Модуля (`0483:5740`) один раз запрашивает разрешение USB. Устройство не открывает, интерфейсы не захватывает, ничего не пишет.
3. Открывается само при подключении Модуля: фильтр `USB_DEVICE_ATTACHED` по VID/PID.
4. Без Gradle и без библиотек: Java, `minSdk` 26, `targetSdk` 30, ABI не важен.

Сборка: `research-tools/g2-probe/build.sh`. Toolchain закреплён в скрипте: JDK 17.0.20.1 (Temurin), `platforms;android-30`, `build-tools;34.0.0`.
Скрипт проверяет пакет, уровни SDK, необязательный `usb.host` и подпись. Ключ отладочный, хранится вне репозитория.
Это исследовательский инструмент. Рабочее приложение по [implementation-plan.md](implementation-plan.md) пишется отдельно.

## Шаги

Автомобиль стоит, зажигание включено.

1. Скопируй `super-radio-probe.apk` на SSD.
2. Подключи SSD к разъёму USB-C со значком USB через переходник OTG. Открой APK файловым менеджером ГУ и установи.
   Если установка запрещена, сфотографируй сообщение и остановись: это blocker G2.
3. Без Модуля открой Super Radio Probe. Сфотографируй весь текст, прокручивая экран.
4. Отключи SSD. Подключи антенну к Модулю, Модуль — к тому же разъёму через переходник.
5. Если появится окно «Открыть Super Radio Probe?» или запрос доступа к USB — сфотографируй и разреши. Галочку «по умолчанию» не ставь.
6. Сфотографируй весь текст приложения с подключённым Модулем.
7. Открой встроенные «Радио» и «USB» и запиши, изменилось ли что-то. Звук громко не включай.
8. Отключи Модуль. Сфотографируй экран приложения ещё раз.

Если на шаге 2 файлового менеджера нет, сфотографируй, что ГУ показывает при подключении SSD.

## Что ищем в отчёте

| Строка | Вопрос |
|---|---|
| `HARDWARE`, `cpuinfo Hardware`, `BOARD` | SA8155P или другой процессор |
| `ABI`, `ОЗУ` | `arm64-v8a`; объём памяти |
| `usb.host` | объявлен ли USB host |
| USB, `0483:5740` | видит ли ГУ Модуль; IF 0–3 и EP как в [descriptor-map.md](../research/descriptor-map.md) |
| `разрешение` | выдаётся ли доступ |
| Аудио, `вход тип 11` | появился ли USB-аудиовход Модуля, частоты и каналы |

Фото кладутся в `raw/g2/`. Отчёт — `docs/research/g2-probe-report.md`; фото не публикуются.
