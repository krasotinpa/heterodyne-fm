# G2, часть 2: диагностическое приложение и тест звука на ГУ

Исполнитель — владелец у автомобиля. Уровень воздействия: установка APK, подключение Модуля, захват звукового интерфейса. Радиокоманд нет.
Цель — узнать процессор, ABI, память, видит ли ГУ Модуль по USB, появляется ли USB-аудиовход и звучит ли радио через прототип звука ([ADR 0001](../adr/0001-audio-path.md)).

## Приложение

`research-tools/g2-probe/` — Super Radio Probe 0.2: кнопка «Тест звука 30 с», строка состояния теста и отчёт.

1. Отчёт только читает: `Build`, `/proc/cpuinfo`, объём ОЗУ, список USB-устройств и аудиоустройств.
2. Для Модуля (`0483:5740`) один раз запрашивает разрешение USB.
3. Тест звука — только по кнопке: открывает Модуль, захватывает IF 1 с `force`, выбирает alt 1, читает изохронный поток через usbfs и играет его через `AudioTrack` на громкости 0,3.
   Через 30 с или по «Стоп»: остановка потока, alt 0, освобождение IF 1. IF 0, IF 2 и IF 3 не трогаются; радиокоманды не шлются.
4. Открывается само при подключении Модуля: фильтр `USB_DEVICE_ATTACHED` по VID/PID.
5. Без Gradle: Java, `minSdk` 26, `targetSdk` 30; нативная библиотека `libusbiso.so` под `arm64-v8a` и `armeabi-v7a`.

Сборка: `research-tools/g2-probe/build.sh`. Toolchain закреплён в скрипте: JDK 17 (проверено с Temurin 17.0.20.1), `platforms;android-30`, `build-tools;34.0.0`, `ndk;28.2.13676358`.
Скрипт проверяет пакет, уровни SDK, необязательный `usb.host`, обе нативные библиотеки и подпись. Выравнивание кадров проверяется на JVM (`FramesCheck`). Ключ отладочный, хранится вне репозитория.
Это исследовательский инструмент. Рабочее приложение по [implementation-plan.md](implementation-plan.md) пишется отдельно.

## Шаги

Автомобиль стоит, зажигание включено.

1. Скопируй `super-radio-probe.apk` на SSD с файловой системой exFAT или FAT32. Агент собирает APK в `research-tools/g2-probe/build/` и сообщает его SHA-256.
2. Подключи SSD к разъёму USB-C со значком USB через переходник OTG. Открой APK файловым менеджером ГУ и установи.
   Android 11 при первой установке из файла показывает «Установка из этого источника заблокирована» с кнопкой «Настройки».
   Открой её, включи «Разрешить из этого источника», вернись и установи. Остановись и сфотографируй сообщение, только если такого переключателя нет.
   Ошибка «Приложение не установлено» при обновлении означает другую подпись: удали старый Super Radio Probe и установи снова.
3. Без Модуля открой Super Radio Probe из списка приложений. Если на главном экране его нет, ищи в полном списке или в «Настройки» → «Приложения».
   Сфотографируй весь текст, прокручивая экран.
4. Отключи SSD. Подключи антенну к Модулю, Модуль — к тому же разъёму через переходник.
5. Если появится окно «Открыть Super Radio Probe?» или запрос доступа к USB — сфотографируй и разреши. Галочку «по умолчанию» не ставь.
   Предупреждение, что приложение сможет записывать звук через это USB-устройство, ожидаемо: у Модуля есть звуковой интерфейс.
   Если приложение не открылось само, открой его из списка приложений: оно запросит доступ. Модуль виден строкой `0483:5740 <- Модуль`.
6. Сфотографируй весь текст приложения с подключённым Модулем.
7. Открой встроенные «Радио» и «USB» и запиши, изменилось ли что-то. Звук громко не включай. Вернись в Super Radio Probe.
8. Тест звука. Громкость ГУ — малая. Нажми «Тест звука 30 с».
   Ожидается FM 90,3 МГц (Авторадио), на которой Модуль стоял после G6a; что Модуль помнит станцию после отключения питания, не доказано.
   Если слышно ровное шипение, путь звука всё равно работает — запиши это. При громком звуке или треске нажми «Стоп».
   Сфотографируй строку «Тест звука: завершён …» и запиши, что слышно: речь, музыка, шипение, тишина, щелчки.
   Если строка начинается с «ошибка», сфотографируй её: это главный результат для ADR 0001.
9. Отключи Модуль. Сфотографируй экран приложения ещё раз.

Если на шаге 2 файлового менеджера нет, сфотографируй, что ГУ показывает при подключении SSD.

## Что ищем в отчёте

| Строка | Вопрос |
|---|---|
| `HARDWARE`, `cpuinfo Hardware`, `BOARD` | SA8155P или другой процессор |
| `ABI`, `ОЗУ` | `arm64-v8a`; объём памяти |
| `usb.host` | объявлен ли USB host |
| USB, `0483:5740` | видит ли ГУ Модуль; IF 0–3 и EP как в [descriptor-map.md](../research/descriptor-map.md) |
| `разрешение` | выдаётся ли доступ |
| Аудио, `вход тип 11` | появился ли USB-аудиовход Модуля, частоты и каналы |
| Тест звука | слышна ли станция; байт против ожидаемых, плохие пакеты, смещение кадра, уровень, недогрузки `AudioTrack`; текст ошибки, если есть |

Фото кладутся в `raw/g2/`. Отчёт — `docs/research/g2-probe-report.md` с SHA-256 установленного APK; фото не публикуются.
После отключения и повторного подключения Модуля приложение запрашивает доступ заново.
