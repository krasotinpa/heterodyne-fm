# G2, часть 4: автозапуск после включения двигателя

Исполнитель — владелец у автомобиля. Радиокоманд нет. Билет #63.
Цель — узнать, доходят ли `BOOT_COMPLETED` и `USB_DEVICE_ATTACHED` до стороннего приложения, через сколько секунд, и сколько времени живёт приложение после выключения зажигания.

## Приложение

Super Radio Probe 0.4 (`research-tools/g2-probe/`). Отличия от 0.3:

1. Приёмник `BootReceiver` пишет в журнал `BOOT_COMPLETED`, `LOCKED_BOOT_COMPLETED`, `USB_DEVICE_ATTACHED`, `ACTION_SHUTDOWN`. В строке — секунды с загрузки ГУ и состояние разрешения USB.
2. Пока сервис работает, он пишет «пульс» раз в 5 с. Последний пульс перед обесточиванием показывает, сколько приложение прожило.
3. Строка «экран: onCreate» содержит секунды с загрузки ГУ. Так видно, запустило ли ГУ экран по подключению Модуля.

Приёмник ничего не запускает. Он только пишет журнал.

## Шаги

Автомобиль стоит, громкость малая, Модуль подключён.

1. Установи APK поверх 0.3. Открой приложение один раз (до этого Android не доставляет события приложению). Нажми «Очистить журнал».
2. Разреши USB в диалоге и нажми «Тест звука 10 мин». Проверь звук.
3. Сон. Выключи зажигание. Подожди 1 минуту. Включи зажигание. Приложение не открывай.
   Через 2 минуты открой Super Radio Probe и сфотографируй журнал целиком.
4. Повтори шаг 3 ещё два раза. Один раз отключи Модуль до выключения зажигания и подключи после загрузки ГУ.
5. Фото лежат в `raw/g2-autostart/`.

## Что ищем в журнале

| Строка | Вопрос |
|---|---|
| `приёмник: …BOOT_COMPLETED, с загрузки N с` | доходит ли событие и через сколько секунд |
| `приёмник: …USB_DEVICE_ATTACHED` | доходит ли оно приёмнику; `экран: onCreate, intent …ATTACHED` — запустило ли ГУ экран |
| `разрешение USB есть/нет` | переживает ли разрешение перезагрузку без диалога |
| последний `пульс` перед обрывом | сколько секунд приложение жило после выключения зажигания (сравни с метками `ACTION_SHUTDOWN`, если есть) |

Отчёт — `docs/research/g2-autostart-report.md`; фото не публикуются.
