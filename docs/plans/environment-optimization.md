# Оптимизация среды: 14 пунктов

Владелец утвердил выполнение плана 16.11.2026.
Каждый пункт выполняется отдельной веткой-worktree и PR; работа идёт последовательно.
Позднее владелец разрешил Codex выполнять merge на время этих 14 пунктов, включая PR #294 и #295.
Разрешение действует только для PR этого плана после локальных проверок и независимого review.
Codex проверяет точный head SHA перед merge. Прямой push в `main` остаётся запрещённым.
Разрешение не распространяется на другие задачи и прекращается после завершения плана или отзыва владельцем.
Работу можно продолжать в текущем чате; отдельный чат не требует повторного согласования каждого пункта.
Правила USB, whitelist и испытаний владельцем сохраняются.
