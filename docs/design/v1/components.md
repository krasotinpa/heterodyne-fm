# Heterodyne FM — компоненты

Все размеры в dp, шрифты в sp. Цвета — имена токенов из `tokens.json` и `tokens.md`. Значения ниже измерены в `prototype.html`, где 1 px = 1 dp.

## 1. Общие правила

- Минимальная цель нажатия — **48 dp**. Видимая часть может быть меньше, только если цель дополнена отступом. В прототипе таких случаев нет.
- Видимая реакция на нажатие появляется в первом кадре, без анимации: кольцо 3 dp цвета текста кнопки, серое наложение 30 % и сжатие до 0,98 со сдвигом вниз на 1 dp (`state.pressed`).
- Фокус с клавиатуры: обводка 3 dp цвета текста, отступ 2 dp (`line.focus`).
- Кнопки узнаются по заливке, форме и значку, рамок у них нет. Исключения: рамка «Стоп» (`edge`) и рамка «Закрыть» на красном баннере (`text`).

Кнопка «Стоянка» рисует векторную «P» в скруглённом квадрате.

В «Настройках» раздел «Кнопка «Стоянка»» содержит два выбора:

- «Подпись»: «Вкл» (по умолчанию) / «Выкл».
- «Размер пиктограммы»: «Обычный» — `size.parkButton.iconBox` 36 dp (по умолчанию), «Крупный» — `size.parkButton.iconBoxLarge` 44 dp.

Приложение сохраняет оба выбора и применяет их сразу, без перезапуска.

## 4а. Поиск на стоянке и на ходу

Правила R18/R21: без Возможности Поиска группа не рисуется. Место шириной `size.seekGroup.width` остаётся пустым. Долгое нажатие руля ничего не делает.

При наличии Возможности группа «Поиск ◀ ▶» видна, пока признак `driving` ложен. Прототип показывает оба состояния; переключатель «Движение» стоит на Панели проверки.

| Состояние | Группа «Поиск ◀ ▶» | Соседние элементы |
|---|---|---|
| На стоянке (`driving` ложно) | видна: фон `surface`, кнопки 52 × 48, подпись «Поиск» | как обычно |
| На ходу (`driving` истинно) | скрыта (`visibility: hidden`): не видна, не берёт нажатия и фокус, место занято | место 224 × 56 (`size.seekGroup.width` × `size.seekGroup.height`) остаётся пустым; имя Станции, «Стоянка» и колонки стоят на тех же местах |

- Ширина места не зависит от состояния. Подпись всегда «Поиск», без многоточия.
- Во время `Seeking` обе кнопки группы «Поиск» серые (`surface2` / `disabledText`). Вокруг нажатой кнопки вращается дуга `accent`: около 28% периметра, оборот за 1 с. Подпись «Поиск» — жирная, `accentText`.
- В паузе после Поиска обе кнопки группы «Поиск» серые. Кольцо `accent` вокруг нажатой кнопки линейно убывает от полного до нуля: 5 с FM, 15 с AM. Отсчёт R26 начинается при отправке команды; после ответа кольцо показывает остаток этой паузы.
- Кнопки Шага серые только в паузе Шага 500 мс, без кольца. Во время `Seeking` и паузы Поиска Шаг сохраняет обычный вид. Пауза Шага не делает кнопки Поиска серыми. Видимый Эфир нигде не содержит слова «пауза».
- Серые экранные кнопки отбрасывают нажатие без сообщения и команды Приёмнику. Отклонённый Поиск с руля на ходу показывает «Поиск доступен через N с» на 2 с (R24/R26). Пауза не является Причиной выключения R21.
- Снимок Приёмника содержит вид команды, направление, полную длительность и остаток паузы при публикации, а также монотонную отметку публикации. UI считает остаток от этой отметки по монотонным часам, в том числе после возврата на Эфир. Течение времени не вызывает публикаций снимка.
- Доступность нажатой кнопки после Поиска: «Поиск ▶, пауза, осталось N с» (либо ◀). Остаток округляется вверх.
- `disabledText` на `surface2` сохраняет контраст текста ≥ 4,5:1 и значков ≥ 3:1 в обеих Темах и четырёх Палитрах.
- «Стоянка» на ходу выключена: фон `surface2`, текст и значок `disabledText`, нажатия нет. Это не Причина R21, строка состояния её не показывает. Режим стоянки открывается только на стоянке.
- Причина выключения (R21) охватывает «Поиск ◀ ▶» только пока группа видна.
- На ходу Поиск запускает долгое нажатие на руле (R24); экранных кнопок нет.
- Нажатие, начатое на стоянке, при переходе на ход отбрасывается: Поиск запускается только при отпускании на видимой кнопке. Уже идущий Поиск не отменяется.
- В Android скрытие — это `enabled = false` и исключение из фокуса и доступности; защита от запуска на ходу стоит в обработчике, не только в разметке.

## 5. Лупа

- **Когда видна:** только пока палец лежит на шкале FM. В AM Лупы нет, частоту меняют «Шаг ◀ ▶».
- **Положение:** над шкалой, зазор 12 dp, во всю ширину центральной области (852 dp). Лупа выше пальца, поэтому рука, которая тянется снизу, её не закрывает. На время касания Лупа перекрывает нижнюю часть верхней строки.
- **Число видимых Станций:** 7 — выбранная по центру и по 3 с каждой стороны. При ширине окна меньше 1000 dp — 5. У краёв диапазона пустые места остаются пустыми.
- **Выбранная Станция:** заливка `accent`, имя `loupeSel` 22 sp, ширина в 1,6 раза больше соседних. Треугольник 12 dp под Лупой указывает на неё. Станции активной Подборки отмечены звездой.
- **Прилипание:** палец ставит частоту `87,5 + доля × 20,5` МГц, выбирается ближайшая Станция Справочника. Свободных частот нет.
- **Переход:** один раз, при отпускании пальца. Если выбрана текущая Станция, Перехода нет, только включается звук.
- **Отмена:** палец ушёл выше или ниже шкалы больше чем на половину её высоты (42 dp). Лупа становится нейтральной (рамка `edge`) с надписью «Отмена — отпустите палец. Частота не изменится». После отпускания появляется уведомление «Отменено. Частота не изменилась: 88,3».
- **Недоступна:** приёмник не подключён, идёт Переход или показан баннер ошибки.

## 6. Лента Подборки

- Горизонтальная лента без полос прокрутки, листается свайпом.
- Края гаснут на 28 dp только с той стороны, где есть скрытые Станции.
- Протяжка больше 8 dp листает ленту и не выбирает Станцию. Короткое касание выбирает Станцию.
- При смене Станции («Станция ◀ ▶», руль, Лупа, Поиск, плашка Справочника), Подборки или Региона лента плавно (300 мс) ставит целевую Станцию по центру. Ручное положение сохраняется, пока Станция не сменилась.
- Номер на плашке — позиция в Подборке. Порядок совпадает с «Станция ◀ ▶» и кнопками руля (R24 не меняется).

## 7. Режим стоянки

- **Боковое меню слева:** ширина 236 dp, фон `surface`, отступ 16.
  - Сверху «← Эфир» (204 × 56, `accent`).
  - Затем подпись «Режим стоянки» и пункты по 52 dp: Подборки, Настройки, Диагностика, О приложении. Пункт «Режим разработчика» виден, только когда режим включён.
  - Внизу статус «Приёмник: подключён / не подключён».
- **Область содержимого:** 864 × 580 dp, отступы 20 / 24, прокрутка по вертикали.
- **Редактор Подборок:** две колонки по ~400 dp — «Справочник» → «Подборка», между ними стрелка 28 dp. Строки 56 dp, шаг 64. Место вставки вычисляется по середине строки.
- **Настройки:** Регион, Тема, Палитра, вид кнопки «Стоянка», Запуск.
- Раздел **«Приёмник»** виден, только если реестр содержит больше одного вида. Кнопки «Приёмник 1», «Приёмник 2» сохраняют выбор.
  Конкретный вид устройства указан в «Диагностике». Смена доступна только на стоянке.
  Старый Приёмник прекращает звук и закрывает USB до открытия нового.
  При первом обнаружении единственный подключённый Приёмник выбирается сам. Если подключены оба, действует сохранённый выбор.
  Без сохранённого выбора оба ждут выбора пользователя. Отключение выбранного даёт «нет связи», без автопереключения.
- «Сигнал Перехода» и «Предел Поиска» видны, только когда выбран Модуль.
- При одном диапазоне переключатель FM | AM не рисуется. Его место `size.bandButton` остаётся занятым.
  AM-Станция остаётся в Подборке при Приёмнике «только FM». Её плашка выключена.
  Строка состояния показывает «Приёмник не принимает AM», если более приоритетной Причины нет. Руль пропускает AM-Станции.
- Новых элементов уровня, стерео, RDS и спектра нет (R18).
- **Диагностика:** две карточки (версия, вид устройства и связь с приёмником), экспорт Журнала на SSD в три шага, переключатель Режима разработчика.
- **Режим разработчика:**
  - счётчики звука, байт +7, связь;
  - 7 кнопок команд в сетке из 4 колонок;
  - поток кадров моноширинным шрифтом в окне 220 dp с прокруткой.
