## Проверка отказа

До записи эталонов новые сценарии упали с `Missing reference`. Два исходных эталона прошли и сохранили прежние PNG.

Временная подмена светлого эталона ошибки тёмным дала код 1 и одну ошибку `Screenshot frequency-error-1024x600-light-1.3 differs on API 35 (ru-RU, mdpi)`.
Тест записал оба PNG размером 1024×600 в `ui-compose/build/reports/screenshots/`.
Файл `frequency-error-1024x600-light-1.3-api35-actual.png` совпал с восстановленным светлым эталоном.
В `frequency-error-1024x600-light-1.3-api35-diff.png` отдельно проверена маска различий для всех 614 400 пикселей.

При временном раскрытии Поиска на ходу семантический тест нашёл два действия вместо нуля. Gradle вернул код 1.
Изменение для проверки отказа удалено.

После восстановления прошли 14 сравнений PNG и 2 теста семантики.

## Независимое review

Standards (GPT‑6.2 Sol/high) и Spec (GPT‑6.2 Astra/high) прочитали весь diff и результаты первого gate одной волной.
На момент review HEAD совпадал с базой. SHA дерева индекса — `389afdd5d3d4e5fdfb0a3f9279705ab08a7ef270`.
Standards указал на кэш Gradle после записи эталонов и неполноту отчёта. Команда сравнения теперь использует `--rerun`.
Spec указал, что ранний отказ Compose мог пропустить запись PNG. Теперь тест сохраняет последний кадр и исходную причину отказа.

В тёмном сценарии ошибки временно заменена строка подсказки. До исправления тест упал с `assertExists` и не записал изображения.
После исправления тот же сценарий вернул код 1 и записал `frequency-error-1024x600-dark-1.3-api35-{actual,diff}.png`.
Проверка маски насчитала 105 976 изменённых пикселей из 614 400. Исходная ошибка Compose осталась в отчёте теста. Подмена удалена.
