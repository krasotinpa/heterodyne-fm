## Defect and Issue Report

Первая подготовка остановилась до перезагрузки. Фаза из блока 3 ожидала уже установленный Справочник.
Для G переиспользуется общая проверка экспорта без зависимости от обновления Справочника.
Второй стенд остановился до перезагрузки из-за отказа гостевого аудиосервиса. В logcat записаны `TinyalsaSink pcm_write failed` и `Audioserver died`.
При включённом гостевом аудиовыходе и прежнем `-no-audio` полный прогон прошёл. Причина сбоя аудиосервиса не установлена.
В одном повторе после cold boot Android сначала сообщил об открытии Launcher. Runner считал Журнал до появления свежей записи приложения.
После review один свежий AVD подтвердил установку APK, но первый `am start` вернул `Error type 3`.
Runner теперь дожидается `RUNNING_UNLOCKED` у основного пользователя Android. Он открывает MainActivity у пользователя 0 и ожидает первую запись асинхронного Журнала.
Прогон после этих изменений подтвердил оба перехода.
На стенде без USB Журнал записал паузы PCM до 499 мс в одном из повторов. Наблюдение добавлено в [диагностический Issue #245](https://github.com/krasotinpa/heterodyne-fm/issues/245#issuecomment-6969186809) для D/E.
