## Defect and Issue Report

Первый прогон подтвердил экранные проверки. Чтение активных Android-сессий не прошло из-за отсутствия системного разрешения у instrumentation.
Тестовый NotificationListener разрешает получить сессию по штатному API Android. Программа фильтрует сессии по собственному preflight package.
Журнал на эмуляторе подтвердил паузы более 100 мс в Playing при стабильной конфигурации. Замер D добавлен в существующий [#245](https://github.com/krasotinpa/heterodyne-fm/issues/245#issuecomment-6970060199). Причина пауз и слышимость на ГУ не подтверждены.
