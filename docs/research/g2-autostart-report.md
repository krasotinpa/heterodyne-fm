# G2, часть 4: автозапуск после включения двигателя

Дата: 16 октября 2026 года. Автомобиль стоял; громкость ГУ малая; Модуль с антенной подключён. Радиокоманд не было.
Исполнитель — владелец; приложение Super Radio Probe 0.4 ([план](../plans/g2-autostart-plan.md), билет [#63](https://github.com/krasotinpa/super-radio-android/issues/63)). APK SHA-256 `9ab7f068…dfbdf7b`.
Источник — 17 фотографий журнала и текстовые ответы владельца. Фото лежат локально в `raw/g2-autostart/` (`SHA256SUMS.txt`, `sha256sum -c`: OK) и не публикуются.
ГУ: DesaySV G7PH-23MM, Android 11 (API 30). Время — часы ГУ (13:16–13:38).

## Итог

1. **`BOOT_COMPLETED` не приходит.** Три выключения и включения двигателя: ни `BOOT_COMPLETED`, ни `LOCKED_BOOT_COMPLETED` приёмник не записал. Приложение запускал владелец вручную.
2. **Подключение Модуля при загрузке тоже не запускает приложение.** После холодной загрузки Модуль виден на USB (отчёт приложения: «Устройств: 2»), но ни приёмник, ни экран приложения не стартовали сами.
3. **`USB_DEVICE_ATTACHED` приходит только живому процессу.** Один раз Модуль подключили заново, пока приложение было открыто: приёмник записал событие через 137 с после загрузки ГУ. Экран при этом не запустился (`onNewIntent` нет).
4. **Разрешение USB переживает перезагрузку ГУ.** После трёх холодных загрузок тест звука стартовал без диалога. Приёмник записал «разрешение USB есть».
5. **Задержки.** Модуль исчезает с USB (`errno 19`) за ~20 с до `onStop` экрана приложения (20,2 / 19,4 / 20,2 с). Сколько приложение живёт после этого, журнал не показал.
6. **Диапазон.** После каждого включения Модуль работает в AM (владелец). Это его последний режим после G4-10 ([отчёт G2-3](g2-media-report.md)).
Каждый вывод — одно наблюдение.

## Что видно в журнале

1. **Между `onStop` и ручным запуском журнал пуст** во всех трёх циклах. Строка «журнал открыт, старых строк N» стоит сразу перед `экран: onCreate, intent …MAIN`. Значит, процесс стартовал от нажатия владельца, а не от приёмника.
2. **Строка «приёмник: …USB_DEVICE_ATTACHED»** одна: `13:31:36.038`, «с загрузки ГУ 137 с, разрешение USB есть». Процесс жил с 13:31:17.
3. **`errno 19` приходит до остановки экрана.** Сервис сам завершается по ошибке чтения (`stopSelf`), пульс на этом прекращается. Поэтому последний пульс — это момент потери Модуля, а не обесточивания ГУ. Измерение «сколько живёт приложение» план не выполнил. Нижняя граница: ≥ 19,4 с после потери Модуля (экран ещё работал и остановился штатно).
4. **`ACTION_SHUTDOWN` в журнале нет**, `SCREEN_OFF/ON` тоже нет: сервис к этому моменту уже уничтожен, а манифестный приёмник процесс не поднял.
5. **Время до готовности ГУ не измерено.** Владелец запускал приложение вручную через 118–144 с после загрузки; раньше он его не открывал.

## Не проверено

1. Есть ли в настройках ГУ список автозапуска или исключений энергосбережения, куда можно добавить приложение. Приёмник мог быть отключён самой оболочкой DesaySV.
2. Сколько секунд живёт приложение после выключения двигателя до полного обесточивания. Нужен пульс, который не зависит от теста звука.
