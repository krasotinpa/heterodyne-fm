# Данные vcfm.ru: структура, выгрузка, условия использования

Тикет: #28 (часть #27). Дата замеров: 2026-10-15. Сеть использовалась только на чтение (HTTP GET).

## Результат

- vcfm.ru даёт таблицы FM-станций Москвы и Ярославля в HTML. JSON, RSS и API не найдены.
- Явной лицензии и правил использования нет. Есть только оговорка о торговых марках.
- Встраивать копию данных в публичный репозиторий без согласия автора нельзя. Безопасный путь: письменное разрешение автора или открытые источники.

Источник: HTML этих страниц (главная, меню, `gorod.php`).

Колонки таблицы города (заголовки `title` из HTML `gorod.php`):

- ст — статус;
- МГц — частота, формат «90,30»; в `sorttable_customkey` лежит «9030» (МГц ×100);
- Станция; Местная (региональная врезка);
- Место передатчика, Город, Область;
- TRP — мощность передатчика, кВт; дБ — усиление антенны; ERP — излучаемая мощность, кВт;
- st — моно/стерео; dir — направленность; pol — поляризация;
- hA, hS — высота антенны и места;
- RDS, PI; ссылка «ещё» на `tx.php?id=…` (PS, RT, PTY, дата и история изменений).

Колонки «формат» (жанр) нет. Диапазон прямо не указан; его определяют по частоте. Таблица Москвы содержит 68 строк, Ярославля — 30. В строках без названия станции частота есть, названия нет. Статус `p`, `c`, `i` не расшифрован на изученных страницах; семантику не приписываю.

Внимание: в обеих таблицах есть частоты 66–74 МГц (OIRT/УКВ-1), например 68,66 «Радио России» в Ярославле (https://vcfm.ru/radio/tx.php?id=961). Для Android-тюнера это другой диапазон. Фильтр FM: 87,5–108 МГц. В таком фильтре в Москве 53 станции с названием, в Ярославле 23.

## 2. Как выгрузить

- Формат: только серверный HTML (`<table class="sortable">`), UTF-8, PHP/Geeklog. Заголовки: `server: nginx`, `x-powered-by: PHP/5.4.38`.
- JSON, RSS, CSV, API на страницах и в меню не найдены (поиск ссылок по `rss|xml|json|csv|api` в изученных страницах пуст).
- Разбор: `<tr>` с 17 ячейками `<td>`; частота из `sorttable_customkey`.
- `robots.txt` (https://vcfm.ru/robots.txt) запрещает `/docs`, `/search.php`, `/submit.php`, `/backend` и др.; `/radio/` не запрещён.
- Каталог `https://vcfm.ru/radio/` отдаёт 403.
- Страницы рассчитаны на браузер. Для приложения нужен разовый снимок, не парсинг на устройстве.

## 3. Условия использования

Отдельной страницы лицензии, правил или соглашения не найдено. В меню нет такого пункта. Единственные правовые тексты (подвал каждой страницы):

> «© 2026 Victor Rutkovsky»

> «Все торговые марки и копирайты на этой странице являются собственностью их хозяев.»

Страница «О сайте» (https://vcfm.ru/radio/about.php) сообщает: «Сайт поддерживается одним человеком.» Автор принимает уточнения на viru@vcfm.ru, в гостевой, VK и Telegram. Там же указано, что базы собраны «с помощью новых, достаточно полных реестров с государственных сайтов» (реестр лицензий, ФАИС, реестр телерадиовещания).

Требования ссылки на источник нет. Разрешения на повторное использование тоже нет. Из этого следует «все права сохранены» по умолчанию (вывод, не цитата; юридическую консультацию это не заменяет).

## 5. Вывод

1. Встраивать выгрузку vcfm.ru в публичный репозиторий без согласия не рекомендую: лицензии нет, автор — физическое лицо.
2. Если данные нужны, попросить письменное разрешение на viru@vcfm.ru и указать источник в `NOTICE`. Тогда ссылка обязательна по нашему решению.
3. Использовать vcfm.ru как справочник для ручной сверки частот допустимо. Это не копирование.
4. Базовый вариант: свой список из публичных фактов (частота + название), проверенный по эфиру на автомобиле.

### Альтернативы (не проверены, нужна отдельная проверка лицензий)

- Реестр лицензий на вещание Роскомнадзора (https://rkn.gov.ru/); открытая выгрузка не подтверждена: страница `https://rkn.gov.ru/opendata/` недоступна из моей среды (ECONNREFUSED), поиск набора не нашёл.
- ФАИС и реестр частотных присвоений (источник данных vcfm.ru по его же описанию); условия доступа не изучены.
- РТРС (филиал «Ярославский ОРТПЦ») для сетей «Радио России», «Вести ФМ», «Маяк»: общая информация по проекту модернизации есть в прессе, перечень частот по Ярославлю не найден.
- Википедия: статья «Список радиостанций Москвы» вернула 404 по двум угаданным URL; отдельные статьи станций содержат частоты (например, https://ru.wikipedia.org/wiki/Relax_FM).
