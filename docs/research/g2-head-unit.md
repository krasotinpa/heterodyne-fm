# G2, часть 1: сведения о ГУ по фото

Дата: 15 октября 2026 года. Источник — 13 фото экранов ГУ и консоли, снятые пользователем на стоящем автомобиле.
Это historical observation по экранам настроек, а не опрос системы. Модуль к ГУ не подключался.

## Итог

ГУ работает на Android 11 (API 30), модель G7PH-23MM. Сборка — `userdebug`, а не `user`.
Поверх заводской прошивки стоит русификация Titan-Auto TA-2.0.1; установлены RuStore и сторонние приложения.
Данные идут через один разъём USB-C на консоли; второй USB-C — только зарядка. У Модуля разъём USB-A: нужен переходник.
ABI, версия ядра, поддержка USB host и USB-аудио по фото не устанавливаются.

`userdebug` и тег `eng.hz…` — признак отладочной сборки производителя. В такой сборке обычно доступны `adb root` и отладка.
Включена ли отладка и есть ли «Параметры разработчика», по фото не видно.
В списке приложений есть `丰云悦享` — сервис GAC Toyota. Это согласуется с китайской сборкой Highlander от GAC Toyota.

## Приложения

1. Системные: Навигация, Настройки, Carlink, Apple CarPlay, HUAWEI HiCar, Ассистент, «Кнопка», Календарь, Радио, USB, BT-Музыка, Телефон, Менеджер, RuStore, Сцены.
2. Дополнительные: FMPLAY, RUTUBE, Яндекс Навигатор, Яндекс Музыка, VK Видео, PCRadio, Яндекс Браузер, 2ГИС, HUD Speed, Radio (синяя иконка), Кинопоиск.
3. В разрешениях также видны «Медиа-площадка», `地图` (карты), WebView Shell.

RuStore и сторонние приложения установлены, значит установка APK в системе возможна. Каким способом — магазин, файл или ADB, — не установлено.
Пункт «Неизвестные источники» на фото не попал.
Приложение Radio с синей иконкой не опознано. Это может быть стороннее приложение для USB-тюнера; проверить у пользователя.
Встроенное «Радио» — вероятно, штатный тюнер автомобиля; к Модулю отношения не имеет. Гипотеза.

## USB

На консоли под подлокотником два разъёма USB-C:

| Разъём | Значок | Назначение |
|---|---|---|
| Левый | USB (трезубец) | данные; вероятно, CarPlay, HiCar и USB-музыка |
| Правый | батарея с молнией | только зарядка |

У Модуля штекер USB-A. Для подключения нужен переходник USB-C (папа) → USB-A (мама) с поддержкой OTG, либо хаб с USB-C.
Работает ли левый разъём как USB host для произвольного устройства, по фото не установлено: это первый вопрос G2.
Ток питания разъёма неизвестен. В G1b Модуль заметно грелся, но ток не измерялся.

## Что это значит для приложения

1. API 30 известен: `minSdk` ≤ 30. Toolchain можно закреплять под API 30; ABI для приложения на Kotlin/Java не нужен.
2. Android 11 поддерживает USB host API. Видит ли ГУ Модуль и выдаёт ли разрешение, проверит только подключение.
3. Звук. Если в ядре и HAL есть USB-аудио, вход UAC Модуля появится как `AudioDeviceInfo.TYPE_USB_DEVICE`, и его можно читать через `AudioRecord`.
   Если нет — нужен свой изохронный приём через libusb, как в Приложении производителя. Это развилка ADR; решается измерением на ГУ.
4. Сборка `userdebug` может дать ADB и `logcat`. Это сильно упростит G2, но требует включить отладку — решение владельца.

## Не установлено

1. ABI и процессор.
2. Версия ядра и уровень патча безопасности: на фото их нет.
3. Есть ли «Неизвестные источники» и «Параметры разработчика».
4. Работает ли разъём данных как USB host для Модуля.
5. Есть ли в системе USB-аудио вход.
