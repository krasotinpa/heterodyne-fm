# Каталог команд Модуля

Каталог — единственный источник whitelist. Команда попадает в whitelist только решением владельца и с указанием, сколько отправок разрешено.
Источник байтов — статический анализ Приложения производителя ([vendor-apk-analysis.md](vendor-apk-analysis.md)). Остальные команды из его таблицы в whitelist не входят.

Кадр команды строится по модели B: `FA 55 | SEQ | LEN (BE) | тело | сумма`. Функция `build_frame` в `research-tools/analyze_session.py` строит его и покрыта тестом.

## Whitelist

| Команда | Направление, endpoint | Кадр (SEQ 0) | Разрешено | Решение |
|---|---|---|---|---|
| requestAllInfo | хост → Модуль, CDC bulk OUT `0x03` | `FA 55 00 00 04 80 85 07 F4` | одна отправка в эксперименте G4-1 — выполнена | владелец, 14 октября 2026 года |

## requestAllInfo

| Поле | Значение |
|---|---|
| Тело | `80 85 07` + сумма `F4` |
| Параметры | нет |
| Где шлёт Приложение производителя | `DabService.MailBox`, события 3 (возврат в приложение) и 39 (после подключения) |
| После отправки (G4-1) | через 0,5–2,4 мс пришли `0x27`, `0x22`, `0x24`, `0x21`; связь выведена по времени; см. [g4-1-report.md](g4-1-report.md) |
| Тайм-аут наблюдения | 120 с после отправки |
| Побочные эффекты | G4-1, 120 с: переподключения нет, cid тот же; байт +30 в `0x22` изменился, смысл неизвестен |
| Повтор | запрещён в G4-1 |
| Доказательства | `Utils.requestAllInfo`, `DabService.send`; эксперимент G4-1, `evidence/g4-20261014T181220Z/` |
| Дальнейшие отправки | не разрешены до нового решения владельца |

## Не в whitelist

TUNE, SEEK, BAND, AS, areaSelect, playSelect, favorSet, KEY*, прочие запросы и любые байты вне таблицы приложения.
Поля `sourceReq`, `requestVersion`, `mcufile` не используются приложением и исключены навсегда без отдельного решения.
