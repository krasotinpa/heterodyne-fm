# Задача проекта Super Radio Android

## Результат

Создать Android-приложение для USB Super Radio FM на штатном Android-ГУ китайского Toyota Highlander 2026 2.0T.
Результат разработки: исходники, воспроизводимая сборка, APK, диагностика и подтверждённые испытания на конкретном ГУ.
Этот handoff готовит разработку. Он не подтверждает её аппаратную реализуемость.

## Исходные сведения

| Сведение | Статус |
|---|---|
| VID:PID `0483:5740`, product `DAB usb bridge` | Пользовательские сведения и исторический вывод Windows |
| Составное USB, MI_00 `DAB usb bridge` | Исторический вывод; класс и назначение неизвестны |
| MI_02, COM5, USB Serial Device, `usbser` | Исторический вывод; COM может измениться |
| Super Radio FM, SMA-антенна, заявленный RDS | Сведения пользователя; функции требуют проверки |
| Сырой файл 1 720 байт | Прочитан независимо, приложен с SHA-256 |
| Android/API, USB host и audio route ГУ | Неизвестны |

Подробности: [hardware-protocol-notes.md](research/hardware-protocol-notes.md).

## MVP и границы

MVP означает минимальную работающую версию. Здесь MVP включает FM, ручную настройку, поиск, пресеты и звук.
RDS добавляется при наличии подтверждённых данных устройства.
Если звук недоступен, результат называется исследовательским прототипом. Он не является полным MVP.

После проверки связи нужны крупные элементы управления, настройка, поиск и пресеты.
Интерфейс различает запрошенную и подтверждённую частоту.
Испытания проводятся на стоящем автомобиле, с малой начальной громкостью.

Первый релиз не требует DAB, Android Auto, CAN, рулевых кнопок, root или прошивки.
Облако, авторизация, телеметрия и распространение чужого APK не входят в задачу.
DFU, bootloader, EEPROM, factory commands и неизвестные vendor requests исключены.

## Варианты решения

| Вариант | Условие | Ограничение |
|---|---|---|
| Прямой USB и собственный протокол | Есть host, воспроизводимые команды и аудиотракт | Рекомендуемая цель; требует исследований |
| Официальный SDK продавца | Есть контракт, SDK и совместимая лицензия | Проверить ABI, зависимости и доступность OEM API |
| Внешний мост или другое ГУ | Штатный порт/аудио несовместимы | Изменяет аппаратную схему; отдельное решение владельца |

Первый вариант является рабочей гипотезой. При аппаратном препятствии агент сохраняет доказательства и предлагает варианты.
Не заменяй цель имитацией радио или демонстрацией UI.

## Рабочая среда

Windows используется для USBView, USBPcap и первого прототипа.
WSL2 Ubuntu и VS Code Remote используются для разработки и offline анализа.
Python: 3.12. Kotlin — предварительный выбор Android языка.
Точный дистрибутив, Linux path и версии Android toolchain выбираются по фактическому окружению.

Пользователь создаёт каталог и GitHub-репозиторий. Изменения выполняются в отдельном WSL worktree.
Один исполнитель реализует связные блоки. Один независимый reviewer проверяет итоговую ветку и не меняет код.
