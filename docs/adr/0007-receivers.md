# ADR 0007: Приёмники

Статус: принято владельцем 27.10.2026 на grilling-сессии ([#157](https://github.com/krasotinpa/heterodyne-fm/issues/157)). Решения 7 и 9 частично заменены [ADR 0008](0008-fm-only.md).

## Контекст

1. Приложение привязано к Модулю: `ModuleController`, whitelist команд, таблица R26, проверка `0483:5740` в `UsbDiscovery`.
2. Владелец 26.10.2026 оставил два приёмника: текущий Модуль и RTL-SDR V4. TEF6686 вне объёма (#150).
3. Модуль отдаёт готовый звук UAC1 и подтверждает частоту кадром `0x22`. RTL-SDR отдаёт IQ-поток, звук делает само приложение, аппаратного Поиска нет.
4. R18 запрещает показывать недоказанное: уровень сигнала, stereo, lock и RDS.

## Решение

1. **Термины.** **Приёмник** — общее понятие. **Модуль** и **RTL-SDR V4** — два вида Приёмника. Пользователь видит слово «приёмник»; конкретное устройство называется только в «Диагностике». Определения лежат в CONTEXT.md.
2. **Объём.** Поддерживаются два вида. Другие Приёмники добавляются только по запросам пользователей.
3. **Интерфейс.** Узкий и общий: подключение, Переход, Шаг, Поиск, диапазон, подтверждённая Станция, состояние связи, звук, отключение. Таблица R26, очередь команд и разбор кадров остаются в адаптере Модуля. Адаптер RTL-SDR подтверждает Переход сразу после настройки. Шаг RTL-SDR на FM равен 100 кГц.
4. **Определение вида.** Реестр профилей: у каждого вида своя пара VID/PID и свой профиль дескриптора (R01). RTL-SDR V4 определяется по `0bda:2838` и строкам дескриптора. Посторонние RTL2832U не выбираются.
5. **Whitelist.** У каждого Приёмника свой список. Владелец утверждает каждую запись. Для RTL-SDR это управляющие передачи: частота, частота выборки, усиление, сброс буфера. Запись EEPROM, DFU и прошивка исключены.
6. **Один Приёмник.** В работе один. Пользователь выбирает его в Режиме стоянки («Настройки»); приложение помнит выбор. Подключён один — он выбирается сам. Подключены оба — действует сохранённый выбор.
   - Смена выбора только в Режиме стоянки. Старый Приёмник останавливается по ADR 0004, решение 4.
   - Пропавший Приёмник даёт «нет связи» (R12). Автопереключения на другой нет.
7. **Возможности.** Приёмник объявляет фиксированный набор: диапазоны, Поиск, отмена Поиска, RDS, уровень сигнала, стерео. UI рисует элемент, только если Возможность объявлена. Флаг включает тикет, прошедший приёмку на ГУ, а не тип устройства.
   - Модуль: FM, AM, Поиск без отмены. Остальное выключено.
   - RTL-SDR V4 в первом релизе: только FM, Переход и Шаг. Поиск, RDS, уровень и стерео включаются отдельными тикетами.
8. **Поиск RTL-SDR.** Программное сканирование по порогу SNR. Порог измеряется, не угадывается. Поиск будет отменяемым. До него «Поиск ◀ ▶» скрыт, долгое нажатие на руле ничего не делает.
9. **Станция вне диапазона Приёмника.** Подборки и Справочники не фильтруются. Переключатель FM | AM скрыт, если диапазон один. AM-Станция в Подборке видна, Переход выключен, Строка состояния показывает Причину выключения «Приёмник не принимает AM». Кнопки руля пропускают такие Станции.
10. **Потоки (уточнение ADR 0004).** Для RTL-SDR добавляется поток Приёмника: bulk-чтение IQ и вся DSP. Звуковой поток читает готовый PCM из кольцевого буфера и пишет в `AudioTrack`. Бюджет паузы ≤ 100 мс остаётся.
11. **Автозапуск (уточнение ADR 0005).** Работает на выбранном Приёмнике по тем же правилам: один раз на запуск, при `lastPlayed`, с аудиофокусом, без автоповтора. Если выбранного Приёмника нет, автозапуска нет. Для RTL-SDR он использует разрешённые записи его whitelist.
12. **Данные.** Подборки, Регионы и `lastPlayed` общие, миграции файлов нет. Журнал получает поле вида Приёмника у каждой записи; формат кадров Модуля не меняется. Настройки только для Модуля (предел Поиска R08) видны, когда выбран Модуль.

## Рассмотренные варианты

1. **Свой whitelist не нужен для RTL-SDR** (у него нет радио-TX). Отклонён: управляющие передачи пишут регистры и EEPROM с серийником.
2. **DSP RTL-SDR в звуковом потоке.** Отклонён: нарушает гарантию ADR 0004 «не ждёт и не берёт блокировок».
3. **Автопереключение на оставшийся Приёмник.** Отклонён: тихо меняет звук и качество без ведома водителя.
4. **Принимать любые ключи RTL2832U.** Отклонён: тюнеры и антенные входы различаются, проверено только V4.

## Последствия

1. Меняются R01–R08, R10, R12, R18, R24, R25, R26 и исключение автозапуска в AGENTS.md.
2. Тикеты #158, #159, #160, #161 и #165 переписываются под это решение.
3. Список записей whitelist RTL-SDR появляется после исследования в #159 и требует решения владельца.
4. Одновременная работа двух Приёмников не цель v1.
