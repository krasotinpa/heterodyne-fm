# ADR 0006: лицензия проекта и GPL-зависимости

Статус: принято владельцем 27.10.2026 на grilling-сессии ([#156](https://github.com/krasotinpa/heterodyne-fm/issues/156)).

## Контекст

1. В репозитории не было файла LICENSE. Репозиторий публичный.
2. Ветка RTL-SDR ([#150](https://github.com/krasotinpa/heterodyne-fm/issues/150)) требует драйвер RTL2832U. Готовый драйвер librtlsdr имеет лицензию GPL-2.0-or-later. Заголовки `src/librtlsdr.c` и `include/rtl-sdr.h` в osmocom/rtl-sdr (master) говорят «версии 2 или любой более поздней»; остальные файлы не проверялись. На Android librtlsdr работает через libusb (LGPL-2.1).
3. Владелец — единственный автор всего кода репозитория (проверено по `git shortlog`).
4. Владелец хочет оставить возможность монетизации, но модель ещё не выбрал.

## Решение

1. **Лицензия проекта:** GPL-3.0-or-later. Текст в [LICENSE](../../LICENSE) взят с gnu.org (SHA-256 `3972dc9744f6499f0f9b2dbf76696f2ae7ad8af9b23dde66d6af86c9dfb36986`).
2. **RTL-SDR:** линкуем librtlsdr. Свой драйвер на Kotlin отклонён: clean-room (без чтения исходников librtlsdr) слишком дорог, а чтение исходников делает Kotlin-код производной работой.
3. **Монетизация:** откладываем. Модель выбираем в рамках GPL. Двойное лицензирование невозможно: права на librtlsdr принадлежат другим авторам. Условия магазинов приложений проверяем отдельно.
4. **Вендорский APK:** остаётся только локально в `raw/`. В репозиторий не попадают APK, декомпилированный код и его цитаты. Факты о протоколе пишем своими словами; храним SHA-256 и анализ.
5. **Внешние вклады:** принимаем под GPL-3.0-or-later с DCO ([CONTRIBUTING.md](../../CONTRIBUTING.md)).

## Модуль

1. Код работы с Модулем наш. Он идёт через Android USB API (изохронный приём UAC1 по [ADR 0001](0001-audio-path.md) и CDC-команды). В репозитории нет файлов `.so`, APK и JAR производителя, а `libusb` в коде приложения не встречается.
2. librtlsdr и libusb относятся только к RTL-SDR. Приложение собирается одним APK, поэтому GPL охватывает его целиком, включая часть Модуля. Для владельца это ничего не меняет, пока он автор этой части.
3. Протокол Модуля восстановлен ради совместимости по статическому анализу APK ([vendor-apk-analysis.md](../research/vendor-apk-analysis.md)). Правовой статус такого анализа в юрисдикции владельца не проверялся. Перед продажей приложения нужна консультация юриста.
4. В тексте и в магазине приложений проект называется независимой разработкой, не связанной с производителем Модуля.

## Последствия

1. Нужны NDK и JNI. [ADR 0002](0002-stack-kotlin-compose-gradle.md) получает пометку.
2. libusb подключаем динамической `.so`. USB-дескриптор передаёт Java, как в `rtl_tcp_andro`.
3. Версию librtlsdr закрепляем по SHA и сохраняем заголовки авторства.
4. Каждая сборка идёт с текстом лицензий, [NOTICE](../../NOTICE) и исходниками.
5. Каждую новую зависимость проверяем на совместимость с GPL-3.0 до добавления (правило в AGENTS.md).
6. Тикет [#157](https://github.com/krasotinpa/heterodyne-fm/issues/157) (ADR «Приёмник») разблокирован.
