# Точка входа для Codex

Проект содержит работающее Android-приложение Heterodyne FM для штатного ГУ Highlander.
Прочитай [AGENTS.md](../../AGENTS.md), [requirements.md](../requirements.md) и [архитектуру](../architecture.md).
Далее выполняй [процесс разработки Codex](codex-implementation.md).

## Текущее состояние

1. Приложение использует Kotlin/Compose, Android USB и собственный приём звука через usbfs.
2. Реализованы управление Модулем, Станции и Подборки, фон, руль и Диагностика.
3. Границы Приёмника описаны в ADR 0007. Готовность конкретного адаптера проверяй по коду и Issue.
4. Приёмка на ГУ завершена частично. Результаты относятся к указанным в отчётах сборкам.

Источники состояния: [отчёт прогона 3](../acceptance/report-run3.md), открытые GitHub Issues и PR.
Историю исследований хранят `docs/research/` и `evidence/`. Исторический пакет `docs/handoff/` не редактируется.

## Начало сессии

1. Проверь точные distro, repository, branch, worktree и SHA.
2. Прочитай задачу, её зависимости и список затрагиваемых файлов.
3. Для изменений создай отдельный worktree от актуального `origin/main`.
4. Примени Ponytail перед кодом. Для поиска используй Graphify.
5. Выполни test-first, полный gate и независимое review по процессу Codex.

```text
Задача → актуальная база → worktree → код и проверки → review → PR
```

Codex не открывает оборудование. Испытания на ГУ выполняет владелец.
