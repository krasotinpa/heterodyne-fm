# Интеграции проекта

Обычная разработка Heterodyne FM не требует корпоративных Wiki, Tracker или NetBox MCP.
GitHub обслуживается `gh` по правилам issue tracker; глобальные подключения для других проектов сохраняются.

## Рекомендуемый запуск

Используй [задачи VS Code](../../.vscode/tasks.json) либо `python3 build-support/codex-project.py` с параметрами [режима прав](codex-permissions.md).
Launcher читает текущий список MCP и передаёт каждому найденному серверу `enabled=false` только для запуска.
Он не копирует определения серверов или секреты в repository и не меняет пользовательский config.
Аргументы передаются без shell; неоднозначное имя сервера вызывает отказ до основного запуска.
Чтобы проверить настройки без модели, выполни:

```bash
python3 build-support/codex-project.py mcp list --json
```

Все найденные записи должны иметь `enabled: false`.
Уже работающие процессы и managed App-коннекторы текущего чата этот launcher не отключает.
Параметры владельца, переданные позднее, могут явно изменить настройки; границы задачи всё равно обязательны.

Боковая панель Extension не запускается через задачи терминала автоматически.
Если её интеграции отдельно не проверены, используй проектную задачу CLI в VS Code.
Не подменяй `chatgpt.cliExecutable` для обхода этого различия.
`HETERODYNE_CODEX_BIN` позволяет проверить установленный альтернативный CLI, не меняя настройки Extension.

## Вспомогательный Claude

Companion отключён только в проектном `.claude/settings.json`: он не добавляет hooks и повторную оркестрацию Codex в новые сессии проекта.
Глобальные плагины и аккаунты не удалены.
Если владелец отдельно использует вспомогательный Claude, запуск без его глобальных MCP:

```bash
claude --strict-mcp-config --mcp-config '{"mcpServers":{}}'
```

Это не часть обязательной разработки; агент не запускает Claude по старой инструкции скилла.
Отключённый Playwright plugin сам по себе не выключает отдельный Playwright MCP.

## Совместимость и откат

Проверенная версия Codex не принимает disabled-only запись для отсутствующего сервера без транспорта.
Пустая таблица MCP также не очистила унаследованный список в проверках.
Поэтому launcher задаёт параметры только существующим записям и не требует машинных путей в общем config.
Для возврата к обычным личным подключениям запусти Codex напрямую в другом проекте или по явно согласованной задаче.
Revert этого PR возвращает прежний запуск задач и проектный enabled-state Companion.
Личные определения MCP не требуют восстановления, поскольку не менялись.
