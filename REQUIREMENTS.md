# Требования и приёмка

## Функциональные требования

| ID | Уровень | Поведение | Проверка |
|---|---|---|---|
| R01 | Обязательно | Найти VID/PID и проверенный descriptor profile | Приёмник выбирается; посторонний USB не выбирается |
| R02 | Обязательно | Запросить USB permission и обработать отказ | Denial даёт ноль обменов; повторный запрос работает |
| R03 | Обязательно | Освобождать ресурсы при unplug/ошибке | 10 циклов replug без зависаний |
| R04 | Обязательно | Настраивать FM в подтверждённом регионе | Нижняя, средняя, верхняя частоты; неверные отклоняются |
| R05 | Обязательно | Настраивать AM в подтверждённом регионе | Границы и реальная AM-станция |
| R06 | Обязательно | Показывать подтверждённую частоту | TX, ответ и слышимый результат согласуются |
| R07 | Обязательно | Искать станции в обоих направлениях | Известная станция; корректное завершение при отсутствии |
| R08 | Обязательно | Останавливать/ограничивать поиск | Cancel либо доказанный ограниченный программный поиск |
| R09 | Обязательно | Хранить 12 пресетов на диапазон | Save/select/delete/restart; данные остаются без USB |
| R10 | Обязательно | Воспроизводить реальное радио на ГУ | FM/AM, отключение, 30 минут приёма |
| R11 | Обязательно | Обрабатывать audio focus и route | Подсказка навигации, pause/duck/restore по проверенной политике |
| R12 | Обязательно | Показывать соединение, ошибку и unknown | Отправка команды не означает success |
| R13 | Обязательно | Работать без сети | Настройка, звук и пресеты автономно |
| R14 | Обязательно | Ограничивать очередь, буфер и retry | Garbage, timeout, переполнение |
| R15 | Обязательно | Экспортировать локальную диагностику вручную | Размер ограничен; TX/RX, время, версия; redaction |
| R16 | Обязательно | Воспроизводимо собирать APK | Зафиксированные версии и APK SHA-256 |
| R17 | Условно | Показывать доказанные RDS PS/RT | Fixtures станции, очистка stale текста |
| R18 | Обязательно | Отключать недоказанные capabilities | AM/RDS/seek не включаются по product string |

Точные диапазоны, единицы и шаги задаёт региональный профиль после проверки hardware.
В GUI нет произвольного hex TX. Начальный command whitelist пуст.
Seek выполняется доказанной командой либо ограниченными tune-командами с подтверждённым признаком станции.
RSSI, stereo и lock не считаются доступными заранее.

## Нефункциональные требования

1. USB и аудио работают вне UI thread.
2. Парсер не зависит от read chunk boundaries.
3. Unknown/corrupt данные сохраняются без ложного RadioState.
4. Пресет хранит band, целую frequency, регион и необязательное имя.
5. Toolchain и зависимости фиксируются после получения API/ABI ГУ.
6. Unit tests работают без оборудования.

Проектные пороги MVP: реакция UI до 200 мс; confirmed tune до 3 секунд при штатном сигнале.
Это требования, а не измерения устройства. Search operation ограничена 60 секундами.
Изменение порога требует записи причины и нового критерия.
Timeout даёт ошибку и прекращает повторные команды.

## Критерии полного MVP

1. Подтверждены APK installation, host и permission на конкретном ГУ.
2. R01–R16 и R18 имеют passed-отчёты; R17 оценивается отдельно.
3. Подтверждены слышимые FM и AM станции.
4. Пройдены 30 минут приёма и 10 unplug/replug.
5. Пройден sleep/wake цикл без самопроизвольного TX.
6. Приложены APK, SHA-256, commit SHA, версии и ограничения.

```text
Host/permission → FM + AM → Seek/пресеты → Реальный звук
                → Устойчивость → APK + отчёт → MVP
```

Нет доступной AM-станции — R05/R10 по AM остаются not tested.
Синтетические ответы и записанный звук не заменяют аппаратную приёмку.
